04

Fuel and workspace

A model has to be held in memory while it runs. Whether that memory is your GPU's VRAM or your system RAM decides whether answers come back in seconds or in minutes. This plate is how to predict which one you'll get.

Two kinds of memory

  • VRAM — memory on the graphics card. Small (often 8–24 GB) but the GPU reads it fast, so a model that fits entirely in VRAM runs quickly.
  • System RAM — the main memory (often 16–64 GB). Plenty of room, but the CPU is far slower at the kind of math a model needs.

Ollama loads as many of the model's layers into VRAM as will fit — this is GPU offload — and runs the rest on the CPU from system RAM. All-in-VRAM is fast. A few layers spilling to RAM is much slower, because every token has to wait on the slow part. No GPU at all means the whole thing runs on the CPU: it works, but expect to read replies as they trickle in.

Why VRAM is "the number" When people ask "will this model run well on my box," they're really asking "does it fit in VRAM." That single comparison — model size versus VRAM — predicts the experience better than anything else.

Will it fit? — a calculator

Set the model size, the quantization, and your hardware. The estimate uses the same rule of thumb setup.sh prints at the end of its run: a 4-bit model needs roughly its parameter count in billions × 0.6–0.75 GB, plus a bit of headroom for the context window.

These are ballpark figures for reasoning about choices, not a benchmark. Real usage depends on the GPU model, the context length you run, and what else is using memory.

With 12 GB VRAM, that box runs qwen3:8b at Q4 (~5–6 GB) entirely on the GPU, with room for a long context. A 14B model at Q4 (~9 GB) still fits. Start with the model setup.sh pulled. Move up a size only if the answers aren't good enough and the calculator says the bigger one still fits your VRAM.

The one-line version Compare model size to VRAM. Fits in VRAM: fast. Spills into RAM: slow. No GPU: slowest. Quantization is the lever that changes the model's size; the context window is a smaller, second cost on top.

Self-check

1. Your GPU has 8 GB VRAM. Which model will run fastest?

Only the 7B Q4 model fits inside 8 GB of VRAM. The others spill into system RAM and run on the CPU for the overflow, which is much slower.

2. The setup report shows No NVIDIA GPU detected and 32 GB RAM. What does that mean for qwen3:8b?

No GPU means CPU-only inference. 32 GB of RAM is plenty of room for an 8B model; the limit is speed, not capacity.

3. Same model, same hardware — you switch from Q4 to FP16. What changes?

FP16 stores each parameter in ~16 bits versus Q4's ~4.7, so the model is about 3× larger. A model that fit in VRAM at Q4 can easily stop fitting at FP16.
